# Documentation

## Files in this directory

- **executive-summary.md** — 1-page project overview for hackathon
- **technical-report.md** — Detailed technical implementation (≤10 pages)
- **architecture/** — System architecture diagrams & design docs
- **presentation/** — Presentation slides & speaker notes

---

## Hackathon Submission Checklist

- [ ] Executive Summary (1 page)
  - Project title & theme
  - Problem statement
  - Solution overview
  - Innovation highlights
  - Team composition

- [ ] Technical Report (max 10 pages)
  - Introduction & motivation
  - System architecture
  - ML model details
  - Geospatial analysis approach
  - Results & evaluation
  - Future enhancements

- [ ] Prototype (web application)
  - Live demo working
  - All 7 pages functional
  - Before/After slider working
  - AI detection visible

- [ ] GitHub Repository
  - Well-organized code
  - README with setup instructions
  - Commit history showing progress

---

## Presentation Tips

- Demo should take 2-3 minutes max
- Focus on the wow factor (Before/After slider)
- Show: Image → Detection → Evolution → Impact → Risk → Response
- Be ready to answer: "How would you scale this?"
